# FastUse Mod

Enhance your Minecraft experience with the FastUse Mod for Fabric.

## Features

- **Hold Mode**: Hold the activation key to continuously use items.
- **Toggle Mode**: Toggle the activation key to enable/disable the FastUse system.
- **Smart Mode**: Automatically detect and use throwable items based on context.

## Requirements

- Minecraft 1.21.11
- Fabric Loader
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/fastuse-mod/releases).
2. Place the mod file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric loader.

## Usage

1. Open the in-game settings screen to configure the mod.
2. Use the configurable activation key to activate the FastUse system.
3. Toggle between Hold Mode, Toggle Mode, and Smart Mode as needed.

## Configuration

- **Activation Key**: Configurable key to activate the FastUse system.
- **Item Category Toggles**: Enable or disable specific item categories.
- **Use Delay**: Adjust the delay between item uses.
